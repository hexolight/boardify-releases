# Boardify

Akıllı tahtalar için PDF üstüne kalemle yazma ve beyaz tahta uygulaması.

Bu depo yalnızca kurulum dosyalarını barındırır. İndirme: [Sürümler](https://github.com/hexolight/boardify-releases/releases/latest)

- Tanıtım sitesi: https://boardify-info.vercel.app
- Tarayıcıda kullanın: https://boardify-tr.vercel.app

## Kurulum (Pardus / Debian / Ubuntu, 64 bit)

```bash
sudo apt install ./boardify_1.0.1_amd64.deb
```

Uygulama menüsünde **Boardify** olarak çıkar. Kaldırmak için: `sudo apt remove boardify`
